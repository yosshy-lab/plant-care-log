# 塊根植物記録

塊根植物ごとの水やり、薬剤散布、植え替え、施肥、状態・写真などをブラウザ内へ記録するWebアプリです。

- テスト環境: https://yosshy-lab.github.io/plant-care-log/
- 本番環境: https://hibikorekaikon.github.io/plant-care-log/

## 主な機能

- 植物情報の登録・編集・並べ替え、複数タグによる整理と絞り込み
- 複数株のタグ・管理場所・生育区分・管理状態の一括編集
- 水やりなどのケア記録と過去日時への追記
- 単発・日単位・週単位・月単位のケア予定
- 複数株へのまとめてケア予定
- 複数株へのまとめてケア記録
- 株に紐づかない備忘録・予定（メモ・繰り返し対応）
- 複数株へのまとめて水やり
- ケア履歴の確認・編集・削除
- カレンダーからケア済み記録・予定を直接編集、削除
- リスト／2列表示の切り替え
- カレンダー表示
- ケア予定・備忘録のiCalendar（.ics）書き出し
- 現在地に基づく降水量と市区町村名の表示、降雨の水やり記録
- JSON形式のバックアップ・復元
- iPhoneショートカット用URL
- 新バージョンの初回案内とメニュー内の更新情報
- 自動・ライト・ダークを選べる表示テーマ（自動は端末設定に連動）

## 保存について

植物情報、ケア履歴、備忘録・予定、設定はLocalStorage、写真はより大容量のIndexedDBへ保存されます。アカウント同期やクラウド保存は行いません。

端末の故障・変更、ブラウザの履歴やWebサイトデータの削除などで失われる可能性があります。右上メニューの「バックアップを保存」を定期的に実行してください。

Safariの通常タブと、ホーム画面から「Webアプリとして開く」場合では保存領域が異なることがあります。iPhoneでホーム画面へ追加する場合は、原則として「Webアプリとして開く」をオフにし、Safariとして開く運用を推奨します。

詳しくは[プライバシー説明](./PRIVACY.md)と[利用上の注意](./NOTICE.md)をご確認ください。

## 基本操作

1. 一覧画面の「植物を追加」から株情報を登録します。
2. 株カードの「水やり」で通常の水やりをすぐに記録できます。
3. 「＋ ケアを記録」では種類、日時、詳細、メモを指定できます。
4. 株カードをタップすると詳細、編集、履歴、ケア予定、ショートカットURLを確認できます。
5. 同じケアを複数株へ記録する場合は、画面上部または右上メニューの「まとめてケア記録」を使用します。
6. 同じケア予定を複数株へ登録する場合は、画面上部または右上メニューの「まとめてケア予定」を使用します。
7. 株に紐づかない予定は、画面上部または右上メニューの「備忘録・予定」から登録します。
8. カレンダーの日付を選ぶと、今日以前は履歴、未来日はケア予定や備忘録を追加できます。
9. 右上メニューの「予定をカレンダーへ書き出す」から、iPhone、Mac、Googleカレンダーなどで開ける`.ics`ファイルを作成できます。
10. 詳しい操作はアプリ右上メニューの「使い方・ヘルプ」をご覧ください。

カレンダーへの書き出しは一方向です。アプリ側で予定を変更しても、追加済みのカレンダー予定には自動反映されません。同じファイルを繰り返し追加すると重複する場合があります。

## バックアップと復元

- 保存: 右上メニュー →「バックアップを保存」
- 復元: 右上メニュー →「バックアップから復元」
- 復元前のデータは端末内へ一時退避され、「復元前のデータへ戻す」で取り消せます。
- Safariとホーム画面版、または別端末の間でデータを移す場合もバックアップを利用します。

## Fork版への更新反映

本リポジトリをForkして利用している場合は、GitHubのFork画面で「Sync fork」→「Update branch」を実行してください。Fork側のGitHub Pagesが再公開された後、表示バージョンをご確認ください。

## 開発とテスト

静的なHTML・CSS・JavaScriptで構成され、GitHub Pagesで公開しています。

```bash
npm install
npx playwright install chromium
npm test
```

Pull Requestとmain更新時に、デスクトップおよびiPhone 13 Pro Max相当の画面サイズでPlaywrightテストを実行します。

## 免責

本アプリおよびアプリ内ヘルプは、栽培結果、天気情報、薬剤使用などの正確性・完全性を保証しません。ヘルプの一部は生成AIを利用して作成しているため、誤りを含む可能性があります。重要な判断は、製品ラベル、公的情報、専門家の案内なども併せて確認してください。

## JavaScript構成

- `js/storage.js`: LocalStorage、バックアップ、復元
- `js/photo-storage.js`: IndexedDBへの写真保存、既存写真の移行、使用量表示
- `js/ui.js`: 植物・ケア・履歴・メニューなどの画面操作
- `js/reminders.js`: 株に紐づかない備忘録・予定の登録、編集、削除
- `js/calendar.js`: カレンダーの描画、日付選択、履歴・繰り返し予定の表示
- `js/calendar-export.js`: ケア予定・備忘録のiCalendar形式での書き出し
- `js/weather.js`: 位置情報、市区町村名、降水量
- `js/app.js`: 初期表示と起動処理
- `js/analytics.js`: Google Analyticsの同意設定とイベント送信

保存形式とLocalStorageキーは、リファクタリング前との互換性を維持します。
